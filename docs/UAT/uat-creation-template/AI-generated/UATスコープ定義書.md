### カテゴリ A: 認証・アカウント管理

#### A-01: Google アカウントによるログイン（active ユーザー）

| 項目 | 内容 |
|------|------|
| **業務ID** | A-01 |
| **業務名** | Google アカウントによる正常ログイン |
| **対応受け入れ基準** | S-01, S-13 |
| **対応設計書** | acceptance.md, api.md（/api/sync-user）, 02_sequence_diagrams.md（シーケンス1） |
| **前提条件** | テスト対象メールアドレスが allowed_email テーブルに `status='active'` で登録済み |

**業務フロー概要:**
1. ユーザーが `/login` にアクセスし、Google ログインボタンをクリックする
2. Supabase Auth が Google OAuth に遷移し、Google 認証が完了する
3. クライアントが `POST /api/sync-user` を呼び出し、allowed_email テーブルを照合する
4. `status='active'` が確認され、app_user に upsert される
5. `role='student'` の場合は `/chat` へ、`role='staff'` の場合は `/admin` へリダイレクトされる

**テストシナリオ概要:**
- 許可済み生徒メールでログインし、`/chat` にリダイレクトされることを確認する
- 許可済みスタッフメールでログインし、`/admin` にリダイレクトされることを確認する

## 5. 後続工程での対応

### 5.1 UATテストケース設計への展開

本スコープ定義書の各業務フロー（業務ID）は、後続のテストケース設計書（UATスコープ定義書.md → UATテストケース一覧.xlsx）において、以下のルールで展開する。

| 展開ルール | 内容 |
|-----------|------|
| **テストケース ID 体系** | `[業務ID]-TC-[連番]`（例: A-01-TC-01, B-01-TC-02） |
| **正常系・異常系の分離** | 各業務に正常系・異常系・境界値のテストケースを個別に定義する |
| **自動テスト活用** | `pnpm test`（Vitest）で検証済みの項目は「自動テスト検証済み」として記録する |
| **手動テスト対象** | UI 操作・ビジュアル確認・モバイル表示が必要な項目は手動テストで実施する |

### 5.2 テスト実施の優先順位

| 優先度 | カテゴリ | 理由 |
|-------|---------|------|
| **最高** | 認証・アカウント管理（A）、Middleware（K-01） | セキュリティの基盤。失敗すると全機能に影響 |
| **高** | チャット（B）、画像添付（C） | コア機能。生徒の主要ユースケース |
| **高** | 管理機能：許可リスト（F）、スタッフ権限（I） | 運用上の必須機能 |
| **中** | 会話履歴管理（D）、月次レポート（E・H） | 品質向上に関わる機能 |
| **中** | 会話検索（G）、管理ダッシュボード（J） | スタッフの利便性に関わる機能 |
| **低** | 共通 UI（K-02〜K-08） | β 版では重要だが CI/自動テストで補完可能 |

### 5.3 スコープ外事項（β 版非対象）

以下は acceptance.md で明示的にβ版対象外とされているため、本 UAT スコープから除外する。

- E2E テスト（Playwright）の完全網羅
- 多言語対応
- 保護者向け共有機能
- SLA 保証（99.9% 等）
- 大規模負荷テスト（100 名超）
- データの自動物理削除 Cron

### 5.4 既知のリスク・注意事項

| リスク | 対応方針 |
|-------|---------|
| Storage ポリシー未設定による画像表示不可 | テスト実施前に Supabase コンソールで Storage ポリシーの設定を確認する |
| 署名 URL の有効期限（表示用 10 分、アップロード用 60 秒） | テスト実施時は有効期限内に操作を完了させる |
| 月末 Cron テスト（H-05） | dry-run モードで検証し、LLM 呼び出しが不要なことを確認する |
| スタッフ権限管理テスト（I-01〜I-04） | `GRANT_ALLOWED_EMAILS` の設定を事前に確認する |
| モバイルテスト（D-05） | 実機または Chrome DevTools の Device Toolbar（375px 設定）で確認する |
