## 8. 既知の制約・注意事項

| リスク・制約 | 対応方針 |
|------------|---------|
| Storage ポリシー未設定による画像表示不可 | テスト実施前に Supabase コンソールで Storage ポリシーの設定を確認する（必須） |
| 署名 URL の有効期限（表示用 10 分） | TC_C_008 は有効期限が短いため、テスト時間に応じてスキップ可能 |
| 月次レポートの LLM コスト | H カテゴリのテストは Dry Run を優先し、実際の生成は最小限（1〜2 名）に留める |
| Cron テスト（H-05）は月末以外で実施 | 月末以外の日付（2026-03-10 等）でテスト実施すると `skipped: true` で確認可能 |
| スタッフ権限管理テスト（I-01〜I-04）| `GRANT_ALLOWED_EMAILS` の設定を事前に確認し、テスト後は付与した権限を必ず解除する |
| モバイルテスト（D-05） | 実機または Chrome DevTools の Device Toolbar（375px 設定）で確認 |
| Error Boundary のテスト（K-04） | 再現が困難なため、ソースコードの `app/error.tsx` 存在確認を優先 |
| セッション失効テスト（A-06） | Cookie 削除でシミュレーション可能 |
