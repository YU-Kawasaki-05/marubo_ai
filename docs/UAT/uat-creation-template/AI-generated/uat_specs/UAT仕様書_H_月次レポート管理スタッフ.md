## 2. カテゴリ概要

月次レポート管理（スタッフ）カテゴリは、スタッフが `/admin/reports` で全生徒の月次学習レポートを一覧表示・手動生成・再生成・CSV ダウンロードする機能を対象とする。また、Vercel Cron による月末自動生成の動作（dry-run による検証）も含む。テスト優先度は「中」。

**重要な前提事項:**
- **月次レポートの実際の LLM 生成はコストが発生するため、UAT での手動生成テストは dry-run（`dryRun: true`）を優先すること**
- 実際の生成テストを行う場合は、テスト用の少数ユーザー（1〜2名）に対して実施すること
- **H カテゴリのテストは E カテゴリ（生徒向け月次レポート閲覧）よりも先に実施すること**（H カテゴリで生成したレポートが E カテゴリの閲覧テストに必要なため）

|------|------|
| **テストケースID** | TC_H_009 |
| **業務ID** | H-05 |
| **テスト区分** | 正常系（dry-run 検証） |
| **優先度** | 中 |
| **前提条件** | `CRON_SECRET` が設定されており、月末以外の日付でテストを実施する（2026-03-10 は月末ではないため適切）。`CRON_SECRET` の値は Vercel ダッシュボードの Settings > Environment Variables から取得するか、担当エンジニアに確認する |

**操作手順（API 直接テスト）:**

1. `CRON_SECRET` の値を確認する（Vercel ダッシュボード > Settings > Environment Variables > `CRON_SECRET`）
2. ターミナルで以下の curl コマンドを実行する:
   ```bash
   curl -H "Authorization: Bearer {CRON_SECRET}" https://marubo-ai.vercel.app/api/reports/monthly
   ```
   （`{CRON_SECRET}` は実際の値に置き換える）
3. レスポンスを確認する

または DevTools Console から以下を実行する（スタッフとしてログイン中の場合）:
```javascript
fetch('/api/reports/monthly', {
  headers: { 'Authorization': 'Bearer {CRON_SECRET}' }
}).then(r => r.json()).then(console.log)
```

> **注記**: この API テストはスタッフが管理画面から実行する手動生成（POST）とは異なり、Cron からの GET リクエストをシミュレートする。本番環境では Vercel が自動的に実行するため、手動テストは任意とする。

**期待結果:**

| 確認ポイント | 期待値 | 確認方法 |
|------------|--------|---------|
| skipped レスポンス | 月末以外の場合、`{ "data": { "skipped": true, "reason": "not_last_day" } }` が返される | DevTools / ターミナルで確認 |

## 5. 備考

- **LLM コスト警告**: 実際の月次レポート生成には LLM API 呼び出しが発生し、コストが かかる。UAT での実際生成テストは最小限にし、Dry Run を活用すること
- Vercel Cron のタイムアウト（Pro プランで 60 秒）に注意。β版（20名）では全員分の生成に 100〜200 秒かかる場合があるため、実際の月末 Cron では分割処理が行われる。タイムアウトが発生した場合は手動再実行（TC_H_004）で対処する
- `monthly_report` テーブルの `status` 遷移: `pending` → `generating` → `generated` / `failed`
- 生成失敗時は `status='failed'` と `error_message` が記録され、手動で再生成できる（TC_H_005）
- **テスト実施順序**: H カテゴリのテストは E カテゴリよりも先に実施すること（E カテゴリのレポート閲覧テストが H カテゴリで生成されたレポートに依存するため）
