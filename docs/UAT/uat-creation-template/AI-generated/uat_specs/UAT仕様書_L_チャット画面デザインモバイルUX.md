## 2. カテゴリ概要

GFX-46〜49 で実施したチャット画面のデザイン改善（モバイルヘッダー最適化、メッセージ可読性、ウェルカム画面、配色変更）が正しく動作し、既存機能を損なっていないことを確認する。

**主な対象ユーザー:** 塾に通う中学生（13〜15歳）、iPhone / Android のモバイルブラウザ利用

**前提環境:**
- ログイン済み生徒アカウント（active、role: student）
- ログイン済みスタッフアカウント（active、role: staff）
- モバイル端末（iPhone / Android）またはブラウザの DevTools モバイルエミュレーション
- デスクトップブラウザ（Chrome / Safari）

**テスト用デバイス準備チェックリスト（推奨）:**

| デバイス / エミュレーション | 画面サイズ | 用途 |
|---------------------------|-----------|------|
| iPhone SE | 375x667 | 最小サイズの iPhone |
| iPhone 14 Pro | 393x852 | 標準的な iPhone（ノッチ + ホームバー） |
| Android（Pixel 7 等） | 412x915 | Android 代表 |
| デスクトップ（1280x800+） | — | デスクトップ表示のデグレ確認 |

## 4. 統合テストシナリオ

### IT_L_001: モバイルでの一連のチャット体験

| 項目 | 内容 |
|------|------|
| **シナリオID** | IT_L_001 |
| **目的** | 中学生がスマホで初めてアクセスしてからチャットを完了するまでの体験を一連で確認する |

**シナリオ手順:**

1. モバイル端末（iPhone 推奨）で `https://marubo.vercel.app/login` にアクセスする
2. Google でログインする
3. `/chat` に遷移し、ウェルカム画面が表示されることを確認する
4. サジェストボタン「二次方程式の解き方を教えて」をタップする
5. 入力欄にテキストがセットされることを確認し、送信する
6. 「...」応答インジケータが表示されることを確認する
7. AI の回答が流れ始め、Markdown（見出し・箇条書き等）が整って表示されることを確認する
8. 続けて「もう少し簡単に説明して」と入力して送信する
9. サイドバー（ハンバーガーメニュー）を開き、会話が保存されていることを確認する

## 5. 備考

- **実機テスト推奨**: TC_L_005（タッチ操作性）と IT_L_001（一連のモバイル体験）は DevTools エミュレーションでは十分に検証できない。特に iOS Safari の自動ズーム、ホームバー領域、キーボード表示時のレイアウトは実機でのみ正確に確認できる。
- **配色の主観評価**: TC_L_013 の「親しみやすさ」は主観的な評価を含む。可能であれば、対象年齢（中学生）に近いテスターにフィードバックをもらうことを推奨。
- **既存 UAT との関連**: L カテゴリのテストは、B（チャット基本）、C（画像添付）、D（会話履歴）のデグレ確認を兼ねている。B/C/D の全テストケースを再実行する必要はないが、IT_L_002 の統合シナリオで主要フローをカバーすること。
- **GFX-46〜49 の実装順序**: GFX-49（配色）が先に適用された場合、GFX-46〜48 のテスト時に配色が新しくなっている前提でテストする。逆の場合は旧配色のままでテストし、GFX-49 適用後に TC_L_013〜015 を実行する。
