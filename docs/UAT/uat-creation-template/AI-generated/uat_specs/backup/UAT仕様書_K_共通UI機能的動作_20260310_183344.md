## 2. カテゴリ概要

共通 UI・機能的動作カテゴリは、システム全体に横断する共通機能を対象とする。Middleware による認証ガード、`/chat-test` の本番非公開、オフラインバナー、Error Boundary、ローディング表示と 404 ページ、パスワードリセット、XSS 防御（Markdown サニタイズ）、セキュリティヘッダーを検証する。テスト優先度は「低〜高」（機能によって異なる）。

## 5. 備考

- K-07（XSS 防御）は `rehype-sanitize` により AI 回答の Markdown レンダリング時にスクリプトが除去される。自動テスト（`pnpm test`）で検証済み
- K-04（Error Boundary）の手動テストは再現が困難なため、ソースコードの確認（`app/error.tsx`, `app/chat/error.tsx` の存在確認）を優先とする
- K-06（パスワードリセット）は Google OAuth を使用するシステムでは Google アカウントのパスワード変更が行われるため、Supabase のメール/パスワード認証が有効な場合のみ対象とする
- セキュリティヘッダーの確認には DevTools > Network > Response Headers または `curl -I https://marubo-ai.vercel.app/` コマンドも使用可能
