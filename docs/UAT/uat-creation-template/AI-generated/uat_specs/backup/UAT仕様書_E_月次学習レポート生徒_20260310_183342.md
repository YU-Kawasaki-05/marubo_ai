## 2. カテゴリ概要

月次学習レポート（生徒）カテゴリは、生徒が `/reports` ページで自分の月次学習レポートを閲覧する機能を対象とする。LLM が生成した学習サマリー・トピック分布・理解度所見・アドバイス・利用統計が記事形式で表示される。レポートの状態（generated / pending / generating / failed）に応じた表示切り替えも検証する。RLS により他の生徒のレポートが取得できないことも確認する。テスト優先度は「中」。

**前提条件:**
- active 生徒としてログイン済みであること
- テスト用に生成済みレポートが存在すること（スタッフが H カテゴリのテストで事前生成するか、または直接 DB に insert する）

## 5. 備考

- 月次レポートの自動生成は毎月末 23:55 JST に実行されるため、UAT でのテストには事前に手動生成が必要（H カテゴリ H-02 参照）
- レポートのテストデータを作成する場合は、Supabase ダッシュボードの `monthly_report` テーブルに直接 INSERT することも可能
- RLS の詳細な検証は自動テスト（`pnpm test`）で実施済み。本 UAT では基本的なアクセス確認を手動で実施
- レポート本文は Markdown 形式で保存され、`react-markdown` + `remark-gfm` でレンダリングされる
