## 2. カテゴリ概要

会話検索・閲覧カテゴリは、スタッフが `/admin/conversations` で全生徒の会話を検索・閲覧する機能を対象とする。期間・生徒メール・キーワードによる絞り込み、ページネーション、会話詳細パネル（ConversationDetail）の表示、添付画像のサムネイル表示（スタッフ用署名 URL）、N+1 クエリ最適化の確認を検証する。テスト優先度は「中」（スタッフの利便性に関わる機能）。

**前提条件:**
- active スタッフとしてログイン済みであること
- 複数の生徒アカウントが存在し、各生徒にチャット会話履歴が存在すること
- 画像添付付きの会話が少なくとも 1 件存在すること

| **テスト区分** | 正常系 |
| **優先度** | 高 |
| **前提条件** | active スタッフとしてログイン済み、複数生徒の会話が合計 20 件以上存在する |

**操作手順:**

1. ブラウザで `https://marubo-ai.vercel.app/admin/conversations` にアクセスする（または管理ダッシュボードの「会話検索」カードをクリック）
2. 検索条件を入力せず「検索」ボタンをクリックする（または自動表示される場合はそのまま確認）
3. 検索結果テーブルを確認する
4. 20 件以上のデータがある場合は「次へ →」ボタンをクリックし、2ページ目が表示されることを確認する
5. 「← 前へ」ボタンをクリックし、1ページ目に戻ることを確認する

**期待結果:**

| 確認ポイント | 期待値 | 確認方法 |
|------------|--------|---------|
| 全件表示 | 検索条件なしで全件が表示される（1ページあたり 20 件） | 画面確認 |
| テーブル列 | 生徒メール（または表示名）、タイトル（50 文字切り詰め）、作成日時（JST）、メッセージ数 が表示される | 画面確認 |
| 並び順 | 作成日時の降順（新しい会話が上） | 画面確認 |
| ページネーション | 「← 前へ」「次へ →」ボタンが表示され、クリックでページが切り替わる | 動作確認 |
| 現在ページ / 総ページ表示 | 「1 / 3 ページ」等の表示がある | 画面確認 |

## 5. 備考

- 会話詳細のスタッフ用添付画像表示には `POST /api/admin/attachments/signed-url`（Service Role）を使用する。Storage ポリシーの設定状況によっては表示されない場合がある
- N+1 クエリ最適化（TC_G_009）の詳細な検証は自動テストおよびソースコードレビューで実施する
- 生徒の会話は閲覧専用（スタッフは編集・削除不可）
- `/admin/conversations` へのアクセスには `requireStaff()` ガードが適用される
