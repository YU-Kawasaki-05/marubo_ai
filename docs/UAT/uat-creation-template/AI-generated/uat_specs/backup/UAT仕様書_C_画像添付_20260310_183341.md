## 2. カテゴリ概要

画像添付カテゴリは、チャット送信に画像を添付してAIに視覚的な質問を行う機能を対象とする。クライアントサイドのバリデーション（MIME/サイズ/枚数）、Supabase Storage へのアップロード（署名URL方式）、送信済みメッセージでのサムネイル表示と ImageLightbox 拡大表示、署名URL の自動リフレッシュを検証する。テスト優先度は「高」。

**前提条件（テスト実施前確認事項）:**
- Supabase Dashboard > Storage > Policies で、`attachments` バケットの SELECT ポリシー（本人の読み取り）が設定済みであること
- テスト用画像ファイルが用意されていること:
  - `test_ok.jpg`: JPEG 形式、1MB 以下（正常系用）
  - `test_ok.png`: PNG 形式、1MB 以下（正常系用）
  - `test_over5mb.jpg`: JPEG 形式、5MB 超（バリデーション異常系用）
  - `test_invalid.gif`: GIF 形式（MIME バリデーション異常系用）

### C-04: 署名 URL の自動リフレッシュ

#### TC_C_008: 署名 URL 失効後の自動再署名（正常系）

| 項目 | 内容 |
|------|------|
| **テストケースID** | TC_C_008 |
| **業務ID** | C-04 |
| **テスト区分** | 正常系 |
| **優先度** | 中 |
| **前提条件** | active 生徒としてログイン済み、画像付き会話が表示されている。表示用署名 URL の有効期限は 10 分（600秒）|

**操作手順:**

1. 画像添付付きの会話を表示する
2. 表示されている画像の URL をブラウザの DevTools > Network で確認する（`?token=...&expires_in=...` 形式の Supabase Storage 署名 URL）
3. 画像が表示されている状態で 11 分以上待機する（署名 URL の有効期限 10 分を過ぎる）
4. ページをリロードせず、他の操作をしてから画像エリアを再度確認する
5. 画像が自動的に再表示されることを確認する

**期待結果:**

| 確認ポイント | 期待値 | 確認方法 |
|------------|--------|---------|
| 自動再署名 | 署名 URL 失効後に、自動的に再署名が行われ、画像が継続して表示される | 画面確認 |
| エラー非表示 | 「もう一度お試しください」等のエラーメッセージが表示されない（1回の再署名で成功する場合） | 画面確認 |

> **注記**: このテストは 10 分以上の待機が必要なため、テスト時間の都合上スキップ可能。代わりに自動テスト（Vitest）での検証結果を参照すること。

## 5. 備考

- **Storage ポリシーの確認は必須**: テスト前に Supabase Dashboard > Storage > Policies で、`attachments` バケットの SELECT ポリシーが設定されていることを確認すること。未設定の場合、画像は表示されない（403 エラー）
- TC_C_008 の署名 URL 有効期限テストは 10 分以上の待機が必要なため、UAT 当日のスケジュールに応じてスキップ可能
- 画像圧縮（長辺 1280px、JPEG 品質 0.8）はクライアントサイドで自動実行されるため、テスト画像が圧縮されても正常動作
- Storage のパス規約: `{user_id}/{conversation_id}/{message_id}/{uuid}.{ext}`
