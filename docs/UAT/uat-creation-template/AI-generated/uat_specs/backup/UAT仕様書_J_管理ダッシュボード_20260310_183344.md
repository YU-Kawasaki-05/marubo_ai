## 2. カテゴリ概要

管理ダッシュボードカテゴリは、スタッフがログイン後にアクセスする `/admin` ページの表示と、4 つのカードリンク（許可リスト管理・権限管理・会話検索・レポート管理）によるナビゲーション機能を対象とする。スタッフのログイン後ルーティングも検証する。テスト優先度は「中」。

---

## 3. 業務別テストケース

### J-01: 管理ダッシュボードへのアクセスと 4 カードリンク表示

#### TC_J_001: スタッフ用ダッシュボードの表示と 4 カードリンクの確認（正常系）

| 項目 | 内容 |
|------|------|
| **テストケースID** | TC_J_001 |
| **業務ID** | J-01 |
| **テスト区分** | 正常系 |
| **優先度** | 高 |
| **前提条件** | active スタッフとしてログイン済み |

**操作手順:**

1. ブラウザで `https://marubo-ai.vercel.app/admin` にアクセスする（またはログイン後に自動リダイレクトされた状態）
2. 管理ダッシュボードが表示されることを確認する
3. 4 つのカードリンクを確認する
4. 各カードリンクをクリックし、対応する管理画面に遷移することを確認する

**操作手順（詳細）:**

1. ダッシュボードに表示されているカードリンクを確認する:
   - 「許可リスト管理」カード
   - 「権限管理」カード
   - 「会話検索」カード
   - 「レポート管理」カード
2. 「許可リスト管理」カードをクリックし、`/admin/allowlist` に遷移することを確認する
3. ブラウザの戻るボタンでダッシュボードに戻る
4. 「権限管理」カードをクリックし、`/admin/grant` に遷移することを確認する
5. ブラウザの戻るボタンでダッシュボードに戻る
6. 「会話検索」カードをクリックし、`/admin/conversations` に遷移することを確認する
7. ブラウザの戻るボタンでダッシュボードに戻る
8. 「レポート管理」カードをクリックし、`/admin/reports` に遷移することを確認する

**期待結果:**

| 確認ポイント | 期待値 | 確認方法 |
|------------|--------|---------|
| ダッシュボードのアクセス | `/admin` ページが表示される | アドレスバー確認 |
| 4 カードリンクの表示 | 「許可リスト管理」「権限管理」「会話検索」「レポート管理」の 4 つのカードリンクが表示される | 画面確認 |
| 許可リスト管理への遷移 | クリックで `/admin/allowlist` に遷移する | アドレスバー確認 |
| 権限管理への遷移 | クリックで `/admin/grant` に遷移する | アドレスバー確認 |
| 会話検索への遷移 | クリックで `/admin/conversations` に遷移する | アドレスバー確認 |
| レポート管理への遷移 | クリックで `/admin/reports` に遷移する | アドレスバー確認 |

## 4. 統合テストシナリオ

### IT_J_001: スタッフのログインから各管理機能へのナビゲーション

| 項目 | 内容 |
|------|------|
| **シナリオID** | IT_J_001 |
| **目的** | スタッフが管理ダッシュボードを通じて各管理機能にアクセスできることを検証 |

**シナリオ手順:**

1. スタッフアカウントでログインし、`/admin` にリダイレクトされることを確認する（TC_J_003）
2. ダッシュボードの 4 カードリンクを確認する（TC_J_001）
3. 「許可リスト管理」カードをクリックし、`/admin/allowlist` に遷移する
4. ナビゲーションバーから「会話検索」をクリックし、`/admin/conversations` に遷移する
5. ナビゲーションバーから「レポート管理」をクリックし、`/admin/reports` に遷移する
6. ログアウトボタンをクリックし、`/login` に遷移することを確認する（TC_A_007）

**期待結果:** 全ステップが正常に完了する

## 5. 備考

- 管理ダッシュボードへのアクセスには `requireStaff()` ガードが適用される
- Middleware（`middleware.ts`）が SSR レベルでセッションを検証し、未認証の場合は `/login` にリダイレクトする
- 管理画面のナビゲーションバーに表示されるリンク数・ラベルは実装に応じて確認すること
