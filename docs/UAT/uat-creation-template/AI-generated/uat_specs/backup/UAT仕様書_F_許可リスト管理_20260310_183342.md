## 2. カテゴリ概要

許可リスト管理カテゴリは、スタッフが `/admin/allowlist` で生徒・スタッフのメールアドレスを許可リスト（`allowed_email` テーブル）に登録・管理する機能を対象とする。一覧表示・検索・絞り込み、新規登録、ステータス変更、CSV 一括登録、および確認ダイアログ（ConfirmDialog）の動作を検証する。テスト優先度は「高」（運用上の必須機能）。

**前提条件:**
- active スタッフとしてログイン済みであること
- テスト用の新規メールアドレスが用意されていること（例: `uat_test_new@gmail.com`）
- テスト用 CSV ファイルが準備されていること

## 5. 備考

- テスト後のクリーンアップ: テスト用に登録したメールアドレス（`uat_test_new@gmail.com`, `uat_csv_test1@gmail.com` 等）はテスト後に削除または `revoked` に変更すること
- CSV ファイルの文字コードは UTF-8。500 行以内であること
- `PATCH /api/admin/allowlist/:email` の `:email` は URL エンコードが必要（`@` は `%40` に変換）
- `window.confirm` が使用されていないことの確認は重要（TC_F_009）。ブラウザのダイアログではアプリのスタイルが適用されないため
